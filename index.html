Frequently asked questions

Do I need to write Apex?

No. Objects are connected with ready-to-use Flow templates, in a few clicks and without code to write or maintain.

Which objects and fields can I track?

Any standard or custom object, and any editable field on it. History length, the number of tracked fields and other options are configured from the UI.

Where is my data stored?

History for objects is stored natively inside your Salesforce org. Files are backed up to your own R2 storage, and the UI works with both.

Is the history encrypted?

Encryption is optional per configuration. You generate your own keys and can rotate them from the Data Security Manager.

Will it hit governor limits?

UndoEngine is designed to respect Salesforce governor limits, with asynchronous processing and configurable batch sizes for large data volumes.

Can it restore deleted records?

Yes. The Log Manager supports mass restore of deleted records, and files can be restored individually or in bulk.
